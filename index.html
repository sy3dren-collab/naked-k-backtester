裸 K LAB · WINDOWS 本機完整版 V1.0

下載後，從啟動檔開啟回測工作台。

  1. 將 ZIP 完整解壓縮到電腦中的資料夾。
  2. 安裝 Python 3.11 或以上。
  3. 雙擊同資料夾的 start_windows.bat。首次會自動安裝所需套件，請保持網路連線。
  4. 瀏覽器將自動開啟工作台。服務啟動後，也可開啟 http://127.0.0.1:8000。

這是開啟說明頁。完整版需由本機 Python 服務執行，直接開啟 HTML 不會啟動服務。命令視窗請保持開啟；結束時按 Ctrl+C。

工作台提供中文 CSV／Big5 匯入、1／5／15／30 分 K、策略積木與版本、成本及績效、K 棒逐根檢討。先選擇驗收策略，再匯入 examples/acceptance/ 中相同名稱的人工行情，即可檢查操作。

完整使用說明 · 積木規則與驗證範圍

人工行情用於功能驗收，不能代表真實投資績效。Windows 啟動腳本已提供；目前自動化驗證平台為 Linux／Chromium。
