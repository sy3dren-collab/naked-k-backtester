裸 K LAB · WINDOWS 本機回測學習版 V1.1

下載後，從啟動檔開啟回測工作台。

  1. 將 ZIP 完整解壓縮到電腦中的資料夾。
  2. 安裝 Python 3.11 或以上。
  3. 雙擊同資料夾的 start_windows.bat。首次會自動安裝所需套件，請保持網路連線。
  4. 瀏覽器將自動開啟工作台。服務啟動後，也可開啟 http://127.0.0.1:8000。

這是開啟說明頁。完整版需由本機 Python 服務執行，直接開啟 HTML 不會啟動服務。命令視窗請保持開啟；結束時按 Ctrl+C。

新版預設使用新手模式：匯入 CSV → 選一個交易想法 → 先跑基準 → 比較三組設定 → 選定後驗證保留期。系統自動連接積木與停損，並保留進階編輯器、逐筆報表與 K 棒檢討。第一次可按「載入人工示範行情」熟悉操作。
