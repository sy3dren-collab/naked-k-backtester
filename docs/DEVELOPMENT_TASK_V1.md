# Codex 開發任務：裸 K 策略積木回測系統 V1.0

專案名稱：`naked-k-backtester`

## 一、系統基本功能

- [ ] Windows 本機網頁操作介面
- [ ] 匯入歷史 CSV 行情資料
- [ ] 支援日期、時間、開高低收、成交量
- [ ] CSV 欄位自動辨識及手動對應
- [ ] 支援 1 分 K、5 分 K、15 分 K、30 分 K
- [ ] 使用 1 分 K 資料合成其他週期
- [ ] 自訂回測日期區間
- [ ] 支援做多、做空、雙向交易
- [ ] 多空策略可分開設定
- [ ] 支援儲存、載入、複製、刪除策略
- [ ] 每套策略保留版本及參數紀錄
- [ ] 第一版以台指期日盤回測為主
- [ ] 不包含即時報價、自動下單及 AI 策略生成

## 八、積木邏輯控制

- [ ] L01：AND 全部條件成立
- [ ] L02：OR 任一條件成立
- [ ] L03：NOT 排除條件
- [ ] L04：SEQUENCE 依順序觸發
- [ ] L05：COUNT 指定根數內出現 N 次

- [ ] L07：RESET 條件失效後重置

每個條件必須記錄成立時間、積木 ID 與觸發原因。順序積木不得使用尚未確認的未來事件。

- [ ] 開盤 5 分 K 高低點突破＋MA20 出場

每套策略均須驗證進出場時間、價格、觸發條件、交易成本及損益計算。

**開發要求：先完成可驗證的回測引擎，再逐步加入積木與介面。不得為了完成畫面而使用假績效資料冒充實際回測。**
