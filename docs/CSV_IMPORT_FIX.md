# CSV 重複欄名修正

修正畫面上的「CSV 欄位名稱重複，請先調整欄名」問題。舊版會拒絕整份 CSV，包含 Excel 匯出時多出的空白尾欄。

- 未使用的重複欄名、空白欄名不再阻止匯入，檢查報告保留原始欄名與位置。
- 同名欄位用實際位置區分，例如 `開盤價 [第 3 欄]`、`開盤價 [第 8 欄]`。下拉選單與預覽一致，讀值按該欄的位置，不會將後面的同名價格覆寫前面資料。
- 日期／OHLC 有多個候選欄位時不自動猜選，需在欄位對應中手動選擇。沒有歧義的標準欄位仍自動對應。
- 如果原始欄名恰好與系統產生的名稱相同，也會再區分，確保所有欄位均可單獨選取。
- Windows 本機完整版與單檔網頁版的 CSV 解碼、預覽、匯入均套用相同修正，支援 UTF-8、Big5、UTF-16。
- 新的匯入識別碼包含解析器版本。升級後重新選取並匯入 CSV 會重新檢查，不會讀到先前儲存的失敗報告；原始紀錄與歷史回測仍保留。

更新方式：關閉舊程式，解壓縮修正版並啟動。重新選取 CSV，確認欄位對應後匯入。同名必要欄位請對照前 3 筆預覽選擇正確位置。

驗證包含 `tests/test_csv_headers.py`、瀏覽器中的「選錯欄位得到 OHLC 錯誤 → 改選正確欄位 → 完成回測」，以及同名／空白欄位的 Python／JavaScript 一致性測試。未取得使用者的實際 CSV，驗證採人工構造檔案重現畫面中的錯誤。
