# 八套人工行情驗收

此資料夾全部是**人工構造的功能驗收行情**，不是市場歷史資料或投資績效。

每套包含同名 `.csv` 行情與 `.strategy.json` 策略。可直接在工作台選擇對應的內建策略；若要與 `expected.json` 比較，請匯入本資料夾的策略 JSON，因為它使用特別便於人工計算的成本：每點 10、單邊手續費 1、單邊固定稅 0.5、單邊滑價 1 點、1 口。

每套預期恰有 1 筆交易。`expected.json` 列出人工核對的進場時間、進出場含滑價價格、雙邊費稅 3 與淨損益。淨損益為 `(出場價－進場價) × 方向 × 10－3`，成交價已包含滑價，不重複扣滑價。

| 編號 | 驗收策略 |
|---|---|
| 01 | 開盤 5 分 K 突破＋固定停損 |
| 02 | 開盤 5 分 K 突破＋MA20 出場 |
| 03 | HH/HL 回調進場＋結構停損 |
| 04 | 支撐反彈＋確認 K |
| 05 | 壓力突破後回踩 |
| 06 | 假突破反向 |
| 07 | 盤整箱體突破 |
| 08 | 波段突破＋移動結構停損 |

這些資料故意只包含一小段日盤，因此資料檢查會提示尾盤不完整；持倉在最後可用 K 棒強制平倉。完整的預期值與因果測試見 `tests/test_extended.py`。
