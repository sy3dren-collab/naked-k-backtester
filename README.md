# 裸 K Lab — 裸 K 策略積木回測系統 V1 完整版

依 [開發任務](docs/DEVELOPMENT_TASK_V1.md) 實作的 Windows 本機網頁系統：Python 回測核心、獨立交易撮合模組、FastAPI、SQLite，以及不依賴外部 CDN 的策略編輯與 K 棒檢討介面。所有績效由匯入資料實際計算；內建人工行情僅供功能示範。

## Windows 啟動

1. 安裝 **Python 3.11 或以上**，下載並解壓縮完整專案 ZIP。
2. 雙擊 `start_windows.bat`。首次啟動會建立 `.venv`，從套件索引安裝 `requirements.txt` 中固定版本的依賴，因此首次需要網路。
3. 安裝成功後自動開啟本機網頁。之後啟動會重用已安裝環境，回測資料不需上傳外部服務。結束請在命令視窗按 `Ctrl+C`。

專案根目錄 `index.html` 提供開啟說明。完整版有 Python / SQLite 後端，不能只開啟 `static/shell.html`。這個檔案是伺服器範本。之前交付的免安裝單檔 HTML v1.2 原始碼保留於 `legacy/standalone/`，ZIP 另附 `legacy-four-strategies.html`；它僅提供原先四套基礎策略功能，不包含本次新增的完整積木、FastAPI 與 K 棒重播。

在命令列安裝與啟動：

```sh
python -m venv .venv
# Windows:
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m backtester.server --open-browser
# Linux/macOS:
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m backtester.server
```

預設使用本機連接埠 8000，可用 `--port 8001` 調整。`--db 路徑` 可選擇資料庫位置。程式預設只綁定 loopback，供本機單人研究使用。

## CSV 與資料檢查

支援 UTF-8、Big5／CP950 與具 BOM 的 UTF-16，自動辨識或手動切換。支援逗號、分號及 Tab 分隔。可自動對應英文欄名，也支援以下繁體欄位，不用先修改原檔：

```csv
日期,時間,開盤價,最高價,最低價,收盤價,成交量,合約,來源
2024/2/1,08:45:00,17978,17978,17950,17973,3537,MTX202402,資料供應商
2024/2/1,08:46:00,17973,17985,17972,17976,1645,MTX202402,資料供應商
```

- 日期與時間可合併為 `datetime` 或分開對應，支援 `YYYY-MM-DD`、`YYYY/M/D`、`YYYYMMDD`、民國三位年，及 `HH:MM[:SS]`、`HHMM`、`HHMMSS`。無時區視為台灣時間；有 UTC offset 會轉成 UTC+8。
- 重複欄名與空白尾欄會依原始位置顯示「第幾欄」，不需修改 CSV。重複備註等未使用欄位不阻止匯入；日期、OHLC 等欄位有多個候選時需手動選擇，系統不猜選也不覆寫同名欄位的值。詳見 [CSV 匯入修正說明](docs/CSV_IMPORT_FIX.md)。
- 必須是 1 分 K 的開始時間與合法 OHLC。成交量可缺漏；合約與來源可省略，但省略時會清楚記錄來源不完整。
- 檢查重複時間、排序、整分鐘、OHLC、缺棒、非完整日盤與交易時段。不自動補價、不靜默去除重複或重新排序；錯誤會阻止回測，警告保留於結果。
- 選檔後顯示前 3 筆解碼預覽。直接按執行回測也會先完成匯入；手動設定的日期範圍會保留。
- 日盤預設 08:45 至 13:45，以 08:45 對齊 1／5／15／30 分 K，只合成完整區間。夜盤仍保存但不交易。未內建交易所假日或特殊交易日行事曆，可自行排除日期。
- 合約及來源欄位、原檔名稱、編碼與換月時間保留於 SQLite／檢查報告。高週期不得跨合約合成；已知換月前先平倉。未提供合約時，不假設系統能辨識連續合約的換月。

## 策略工作台

左側工具箱可搜尋代碼或名稱；點擊或拖曳新增積木。中央可拖曳調整順序、複製、刪除與啟停；右側編輯詳細參數與引用。實際計算採 ID 依賴順序，禁止循環及不合法的輸出型態。

積木涵蓋 P01–P08、E01–E12、F01–F14、S01–S08、X01–X12、L01–L08，以及均線、價格鎖定與邊緣事件等輔助積木。完整參數由 `backtester/catalog.py` 同時供驗證器與介面使用。詳見 [語意與實作對照](docs/IMPLEMENTATION.md)。

- 價格不能直接作為交易訊號，需經條件判斷。多空可各選不同進場、一般出場、停損與停利積木。
- AND／OR／NOT、A → B → C、COUNT、EXPIRE、RESET、DELAY 可組合。序列必須嚴格先後，不接受同時發生，且只使用已確認的事件。
- 多個一般出場條件預設 OR；多個有效停損採最緊保護價，多個停利採最近的有利價。觸價型停損優先。
- 可選大台／小台／微台與自訂點值，單筆口數可調，仍保持單商品、單一持倉、不加碼、不多空同時持倉。
- 修改策略後儲存或回測，會自動建立下一個版本，不覆寫原版本。可載入、複製或從策略庫刪除；刪除不抹去歷史回測及版本稽核資料。
- 策略摘要列出進出場邏輯、風險配置與啟用積木的完整參數。舊格式策略載入編輯器時，以新版本升級，保留原策略紀錄。

## 成交與避免未來資料

- 訊號在其週期 K 棒結束才成立；預設於同日下一根可用 1 分 K 開盤成交。多週期只能讀取游標當時已完成的 K 棒。
- 波段右側確認完成才可引用；保存候選時間及確認時間。前 N 根區間排除正在判斷的剛完成 K 棒；MA 可以包含剛完成 K 棒。開盤區間須完整形成才可使用。
- 觸價進場是選配：只在確認訊號之後的 1 分 K 內檢查鎖定參考價，不能回到訊號之前成交；期限以主要週期根數計。盤中觸價保留路徑不確定標記，不虛構秒數。
- 停損跳空使用較不利的開盤價，再加不利方向滑價；停利使用目標價再扣滑價。同分鐘同時碰停損及停利，採停損優先並標記不確定。
- 結構停損、訊號 K 與前一根 K 的價位都取訊號時已知資料。跳空後停損無效、超過最大停損／追價距離，或缺少必要結構時取消進場並記錄原因。
- 移動停損在新結構／有利極值確認後更新，只能向有利方向移動，從下一分鐘生效。不能拿新停損回頭套用到剛走完的 K 棒。
- 同棒平倉後不立即反手。預設不跨日；指定時間或日盤最後資料強制平倉。缺少尾盤時用當日末棒，並保留資料不完整警告。
- 每日虧損上限以已實現淨損益阻止新進場，不宣稱可以精確限制盤中浮虧。停損後冷卻依已完成的主要週期時間計算。
- 每個確認事件有固定 ID、時間、版本、積木及原因；EXPIRE 延長一個事件時，不會把同一事件重複用來進場。

成本預設都是可修改的使用者模擬值，**不是最新實際費率**。進、出各計單邊手續費及交易稅；名目稅為 `成交價 × 每點價值 × 單邊稅率 × 口數`，也可選每口固定稅。滑價已反映於成交價，報表額外揭露的滑價成本不能再次扣除。採 IEEE-754 浮點，不套用交易所逐項整元捨入規則。

## 績效與 K 棒檢討

提供交易／多空筆數、總與多空勝率、總獲利／虧損、淨損益、平均交易／獲利／虧損、平均實現 R、獲利因子、最大回撤、最大連續虧損金額、最長連勝／連敗、每日／月度損益、時段績效、資金與累積損益曲線，以及逐筆成交與成本。無虧損時獲利因子顯示「—」；缺少有效初始停損時該筆 R 不計入平均。

最大回撤以每分鐘收盤淨清算值（含估計平倉成本）及初始資金為基準，不代表分鐘內最差浮虧。不同版本的歷史結果可並列比較；比較時請保持資料與日期一致。

點交易紀錄可跳到黑底、紅漲白跌 K 棒圖，顯示成交量、開盤區間、支撐壓力、波段、進出場與停損停利。可切 1／5／15／30 分 K，指定游標、逐根前後或播放。重播 API 不回傳當時未完成的 K、未確認結構或尚未發生的平倉結果；保護價按更新生效時間分段繪製。

## 資料儲存與重現

`data/backtester.sqlite3` 保存匯入內容、來源與檢查報告、標準化行情、JSON 策略版本、回測設定、績效、逐筆交易、訊號、價格確認時間及保護價更新。停止服務後再備份資料庫。匯入識別碼納入 CSV 解析器版本，因此升級後重新匯入不會卡在舊版錯誤報告，也不覆寫舊資料與回測。回測識別碼由資料指紋、完整策略、成本、設定及引擎版本決定，計算不依賴執行時鐘或亂數。

## 驗證與開發

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

八套人工行情驗收包含：開盤突破固定停損、開盤突破 MA20、HH/HL 回調結構停損、支撐反彈確認、壓力突破回踩、假突破反向、箱體突破、波段突破結構移動停損。核對每筆時間、價格、費稅、損益與原因，並測試附加未來行情不改寫既有訊號及結構。

可直接匯入的八套 CSV、策略 JSON 與人工核對預期值位於 `examples/acceptance/`。建立可下載完整專案 ZIP：`python tools/package.py`；產物不包含使用者資料庫、私有行情或 `.venv`。

選用的瀏覽器測試（需 Playwright／Chromium）：

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/browser_smoke.py
```

Linux 系統已有 Chromium 時，可設定 `CHROMIUM_PATH=/usr/bin/chromium`。此測試操作拖曳、版本、複製刪除、八套實際 CSV 回測、JSON 匯出、K 棒跳轉與播放、歷史比較及手機寬度。測試用暫存資料庫。

舊版獨立 HTML 的保留驗證：`python tests/standalone_smoke.py`、`python tests/entry_smoke.py`；`python tests/check_browser_engine.py` 另需 Node 18 以上，只比對舊四策略的 Python／JavaScript 引擎，不代表進階引擎也有純前端版本。

```text
backtester/data.py       CSV、來源檢查及 1/5/15/30 聚合
backtester/catalog.py    所有積木與參數目錄
backtester/schema.py     型態、參數、引用與 DAG 驗證
backtester/blocks.py     已完成行情的價格／條件評估
backtester/matching.py   獨立成交、成本及保護價
backtester/runner.py     事件迴圈、持倉限制、稽核
backtester/examples.py   八套驗收策略
backtester/api.py        FastAPI 與不洩漏未來的重播查詢
backtester/store.py      SQLite／版本歷史
static/                  編輯器、報表與 Canvas K 棒圖
legacy/standalone/       舊版免安裝網頁來源
```

未包含即時行情、實盤提醒、自動下單或 AI 策略生成。雲端驗證平台是 Linux，Windows 啟動腳本及 Windows/Linux CI 已提供，但未宣稱已在實體 Windows 電腦完成操作驗收。
